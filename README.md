# Student Progress Manager

FastAPI API for creating, listing, and updating student progress records.

```bash
pip install -r requirements.txt
uvicorn app:app --reload
```

Open /docs. The MVP stores records in students.json; add authentication, database persistence, and privacy controls before handling real student data.

## Live deployment

- **Frontend:** https://varsha-di-frontend-vijayjangids-projects.vercel.app
- **Backend API:** https://student-progress-api-m0g5.onrender.com
- **API docs:** https://student-progress-api-m0g5.onrender.com/docs

> Deployment is an MVP. Configure required secrets (if any), add authentication, and use durable database storage before production use.
